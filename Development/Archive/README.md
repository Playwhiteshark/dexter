# Development archive

Historical Dexter investigations retained for provenance.

Material here documents decisions or experiments that are no longer part of the
active development surface. Archived scripts are not necessarily maintained against
the current runtime.

Use:

- `Harnesses/` for repeatable current benchmarks.
- `Diagnostics/` for current operational diagnostics.
- `Development/Probes/` for useful developer-only experiments.
- `Development/Archive/` for completed or superseded investigations.

Raw generated benchmark results are kept out of Git. Important conclusions belong in
tracked documentation, GitHub issues, and commit history.
